# 공허의 왕관 · Hollow Crown

아이폰 사파리 가로 화면에서 즐기는 디아블로 방식의 액션 RPG입니다. 디아블로 1의 게임 구조(마을과 16층 던전, 세 직업, 아이템·접사·고유 아이템, 괴물 계열, 명중·방어·막기·경직 공식, 퀘스트)를 거의 그대로 옮겼고, 기술 트리·레어 아이템·허리띠 줄·용사 무리·순간 이동 지점 같은 디아블로 2의 체계를 일부 더했습니다. 규칙과 수치는 위키백과·나무위키와 팬 위키의 자료를 참고했습니다.

이야기·인물·지명과 아이템·괴물 이름은 새로 지었습니다. 잿빛 역병을 멈추려고 대성당 지하로 내려간 성녀 세라핀과, 그녀가 찾아낸 속이 빈 왕관, 그 안에 갇혀 있던 공허의 군주 벨가스에 관한 이야기입니다.

- 빌드 과정 없이 정적 파일만으로 돌아갑니다(바닐라 JavaScript ES 모듈).
- 그래픽은 모두 코드로 그립니다. 아이소메트릭 타일과 벽, 횃불 조명과 어둠, 아이템 아이콘이 그렇고, 캐릭터·괴물도 3차원 뼈대를 투영해 매 프레임 입체 음영으로 그립니다. 천·가죽·쇠·털·괴물 가죽 같은 재질 질감과 때·긁힘을 작은 음영 타일로 구워 덧입히고, 따뜻한 주광과 푸르스름한 그늘, 채도를 낮춘 색으로 디아블로 2 레저렉션처럼 투박한 느낌을 냅니다. 걸을 때는 발이 바닥에 붙도록 역운동학으로 다리를 풀고, 공격·시전·피격·죽음 동작은 준비·타격·마무리로 나눈 키프레임으로 움직입니다. 이미지 파일은 앱 아이콘뿐입니다.
- 효과음 112종, 배경음악 7곡, 지역별 환경음도 음원 파일 없이 Web Audio로 합성합니다. 소리는 워커 스레드에서 만듭니다.
- 가로 화면 전용입니다. 세로로 들면 가로로 돌려 달라는 안내가 나오고 게임이 멈춥니다(아이폰의 세로 방향 고정이 켜져 있으면 화면이 돌아가지 않으니 꺼 두세요).
- 홈 화면에 추가하면 전체 화면 앱(PWA)으로 실행되고, 한 번 연 뒤에는 오프라인에서도 열립니다.

## 플레이

GitHub Pages로 배포하면 `https://akaps1359.github.io/web-game2/`에서 바로 열 수 있습니다.

1. 저장소 **Settings → Pages**에서 *Deploy from a branch*, 브랜치 `main`, 폴더 `/ (root)`를 고릅니다.
2. 잠시 뒤 위 주소가 열리면 사파리에서 **공유 → 홈 화면에 추가**를 눌러 앱처럼 설치하세요.

로컬에서 시험하려면 아무 정적 서버로 저장소 루트를 띄우면 됩니다.

```sh
python3 -m http.server 8000   # http://localhost:8000
```

## 조작

플레이스테이션으로 디아블로를 하듯 조이스틱과 단추로만 합니다. 게임 화면을 눌러서는 아무 일도 일어나지 않습니다.

| 동작 | 방법 |
| --- | --- |
| 이동 | 화면 왼쪽을 누르고 끌면 그 자리에 조이스틱이 생기고, 민 방향으로 걷습니다. 닫힌 문은 밀면 열립니다 |
| 공격 | 오른쪽 아래 큰 단추. 조이스틱을 민 쪽(밀지 않으면 바라보는 쪽)의 가까운 적을 겨누고, 가까운 적에게는 몇 걸음 다가갑니다(활은 멀리서 쏩니다). 누르고 있으면 계속 싸웁니다. 적이 없으면 상호작용 단추와 같습니다 |
| 상호작용 | 공격 단추 위에 손 닿는 곳의 할 일이 적힌 단추가 나타납니다: 줍기·열기·대화·내려가기·올라가기·순간 이동·부수기 등. 그 대상에는 금빛 고리(아이템은 금빛 이름표)가 표시됩니다 |
| 기술 단추 4개 | 탭하면 공격 단추처럼 적을 자동으로 겨눕니다. 단추에서 화면 쪽으로 끌면 원하는 곳을 겨누고, 단추 위로 되돌아와 떼면 취소됩니다 |
| 물약 | 가운데 아래 물약 띠를 탭해 마십니다. 띠 양옆의 빨간 구슬(생명력)이나 파란 구슬(마나)을 탭하면 알맞은 물약을 자동으로 마십니다 |
| 마을 사람 | 가까이 가서 상호작용 단추(대화)로 이야기합니다(사고팔기, 수리, 감정, 퀘스트) |
| 귀환 | 오른쪽 위 파란 단추로 귀환 주문서를 읽어 마을로 가는 차원문을 엽니다 |
| 지도 | 오른쪽 위 작은 지도를 탭하면 전체 지도가 겹쳐 보입니다 |
| 확대·축소 | 두 손가락으로 벌리거나 오므립니다 |
| 창 | 왼쪽 위 단추: 가방, 캐릭터(능력치), 기술, 퀘스트, 메뉴 |

게임은 층을 옮길 때, 마을에 갈 때, 레벨이 오를 때 자동으로 저장됩니다. 다시 불러오면 마을에서 시작하고 던전은 새로 만들어집니다(디아블로 2 방식).

## 들어 있는 것

- **직업 셋**: 전사, 로그, 소서러. 디아블로 1의 기본·최대 능력치, 생명력·마나 공식, 직업별 막기·명중 보정을 따릅니다. 레벨은 50까지 오르고, 레벨마다 능력치 점수 5와 기술 점수 1을 받습니다.
- **기술 트리 56개**(직업마다 세 갈래, 선행 기술과 요구 레벨이 있습니다)

  - 로그(19): 마법·화염·냉기 화살, 다중 사격, 유도 화살, 연사, 빙결 화살, 미끼, 그림자 전사, 화염 폭탄·전격 함정·독 구름·번개 감시탑 같은 함정
  - 소서러(22): 화염탄, 화염구, 화염벽, 메테오, 충전된 화살, 정전기장, 번개, 연쇄 번개, 순간 이동, 에너지 보호막, 얼음 화살, 냉기 갑옷, 서리 노바, 눈보라, 얼음 구체 등

- **괴물 88종**: 디아블로 1처럼 계열마다 4단계 변종이 있고, 층에 맞는 종류가 섞여 나옵니다. 언데드·악마·짐승 구분, 원소 저항과 면역, 고유한 행동(타락귀는 동료가 죽으면 달아나고, 가고일은 돌로 변해 회복하는 식)이 있습니다. 이름 붙은 우두머리는 매우 강함·순간 이동·마나 연소 같은 능력을 갖고 졸개를 거느리며, 용사·광신도·광전사·유령·빙의된 무리도 나옵니다.

## 따른 디아블로 규칙

- 명중률: 근접은 50 + 민첩/2 + 레벨 + 직업 보정 − 대상 방어도, 5–95%로 제한합니다. 원거리와 주문도 디아블로 1 식을 씁니다.
- 방어도는 민첩/5에 장비를 더하고, 막기 확률은 방패와 직업 기본값, 민첩, 레벨 차를 반영합니다.
- 경직: 받은 피해가 캐릭터 레벨 이상이면 플레이어가 움찔하고, 괴물은 레벨+3 이상일 때 움찔합니다.
- 전사는 레벨%의 확률로 피해 2배 치명타를 냅니다. 검은 짐승에게 강하고 언데드에게 약하며, 둔기는 그 반대입니다.
- 경험치는 디아블로 1의 표와 공식(기본 경험치 × (1 + (괴물 레벨 − 캐릭터 레벨)/10))을 씁니다. 캐릭터 레벨이 괴물보다 높을수록 적게 받습니다.
- 생명력은 장비로만 재생되고, 마나는 천천히 찹니다. 물약 회복량은 직업마다 다릅니다.
- 드롭: 골드 약 30%, 아이템 약 11%. 마법 아이템 확률, 고유 아이템 확률, 아이템 레벨에 따른 접사 범위, 가격 공식도 디아블로 1 수치입니다.
- 층 이동 직후 잠깐 무적이 되고, 빛 반경 안의 괴물만 깨어납니다.

## 개발 도구

```sh
node tools/preview/play.mjs <시나리오.mjs> [출력 폴더]   # Playwright로 아이폰 가로 화면을 띄우고 시나리오 실행·캡처
```

`tools/preview/scene.html`은 타일·캐릭터 렌더링을 따로 보는 미리보기, `tools/preview/models.html`은 직업·괴물·보스·마을 사람 모델을 여러 방향과 동작 순간으로 늘어놓아 보는 전시 페이지(예: `?set=classes&faces=4`, `?set=beasts&anim=walk&ts=0,0.25,0.5,0.75`), `tools/preview/bench.html`은 모델 그리기 비용을 재는 페이지입니다. `tools/preview/touch.mjs`는 실제 터치만으로 게임을 시작해 조이스틱 이동·상호작용 단추(대화·줍기·계단)·공격 단추의 겨누기·물약이 되는지 확인하는 시나리오입니다(`node tools/preview/play.mjs tools/preview/touch.mjs`). `tools/audio-test.html`은 모든 효과음·음악·환경음을 하나씩 들어 보는 소리 시험대입니다. 휴대폰에서도 열립니다.

### 파일 구성

- `js/core/`: 난수, 좌표·수학 도구, 화면 고정, 저장
- `js/data/`: 직업, 기본 아이템, 접사, 고유 아이템, 괴물 수치
- `js/game/`: 던전·마을 생성, 시야, 길찾기, 전투 공식, 기술, 괴물 AI, 드롭, 물체, 퀘스트·이야기, 마을 사람, 상점, 게임 진행
- `js/render/`: 아이소메트릭 렌더러, 타일·벽 텍스처, 소품, 아이콘, 효과
- `js/render/fig/`: 인물·괴물 모델(투영·빛·음영 도형, 재질 질감 타일, 자세와 걸음·역운동학, 몸·옷·갑옷, 머리·얼굴·투구, 무기·방패, 네발 짐승·박쥐·뱀)
- `js/ui/`: HUD, 창(가방·캐릭터·기술·퀘스트·상점·메뉴), 대화, 제목 화면, 터치 입력
- `js/audio/`: 효과음·음악·환경음 합성
