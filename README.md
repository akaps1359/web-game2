# 철혈전선 1936

아이폰 사파리 세로 화면에서 즐기는 2차 세계대전 대전략 게임입니다. 하츠 오브 아이언 IV의 규칙(국가 중점·연구·산업·징집·편제·보급·지상전·공군·해군·외교·항복)을 모바일에 맞게 옮겼고, 1936년 1월 1일부터 1945년까지의 실제 역사를 이벤트와 국가 중점으로 담았습니다.

- 빌드 과정 없이 정적 파일만으로 돌아갑니다(바닐라 JavaScript ES 모듈).
- 지도·국기·아이콘·이벤트 삽화는 모두 코드로 그립니다. 이미지 리소스는 앱 아이콘뿐입니다.
- 배경음악도 음원 파일 없이 코드로 작곡하고 기기에서 실시간으로 합성합니다(Web Audio).
- 홈 화면에 추가하면 전체 화면 앱(PWA)으로 실행되고, 한 번 연 뒤에는 오프라인에서도 열립니다.

## 플레이

GitHub Pages로 배포했다면 `https://akaps1359.github.io/web-game2/`에서 바로 열 수 있습니다.

1. 저장소 **Settings → Pages**에서 *Deploy from a branch*, 브랜치 `main`, 폴더 `/ (root)`를 고릅니다.
2. 잠시 뒤 위 주소가 열리면 사파리 **공유 → 홈 화면에 추가**로 앱처럼 설치하세요.

로컬에서 시험하려면 아무 정적 서버로 저장소 루트를 띄우면 됩니다.

```sh
python3 -m http.server 8000   # http://localhost:8000
```

## 조작

| 동작 | 방법 |
| --- | --- |
| 지도 이동·확대 | 한 손가락 끌기, 두 손가락 핀치, 두 번 탭 |
| 주 정보 | 주를 탭(또는 길게 누르기) |
| 사단 이동·공격 | 지도에서 사단 카운터를 탭해 선택 → 목적지 주 탭 |
| 시간 | 위쪽 날짜 탭으로 일시정지/재개, +/−로 속도 조절 |
| 패널 | 아래 탭: 중점·정치·연구·산업·군사·외교 |

군사 패널에서 군을 만들고 **자동 방어/자동 공세**를 켜면 전선 운용을 AI에 맡길 수 있습니다. 연구·생산·무역도 자동으로 돌릴 수 있습니다.

## 들어 있는 것

- **국가**: 독일·영국·프랑스·이탈리아·소련·미국 등 강대국과 유럽·중동·북아프리카의 여러 나라. 어느 나라든 고를 수 있습니다.
- **국가 중점**: 강대국별 고유 트리(독·이·영·프·소·미)와 공통 트리.
- **역사 이벤트 100여 종과 중점**: 라인란트 재무장, 에티오피아 전쟁, 스페인 내전, 안슐루스, 뮌헨 협정, 독소 불가침 조약, 폴란드 침공, 가짜 전쟁, 베저위붕, 황색 작전, 프랑스 항복과 비시, 바르바로사(기습과 공장 소개), 무기 대여, 진주만, 횃불 작전, 천왕성 작전, 허스키 작전과 이탈리아 휴전, 연합군 폭격, 노르망디 상륙, 바그라티온 작전, 독일 항복 등. 이벤트는 신문·전보 형식으로 표시되며 역사와 다른 선택도 할 수 있습니다.
- **외교**: 전쟁 목표 정당화, 선전포고, 독립 보장, 불가침 조약, 군사 통행권, 진영, 백색 평화, 무기 대여(비축 장비 보내기).
- **전투**: HOI4 방식의 시간 단위 공격·방어 판정(전장 너비, 조직력, 돌파, 장갑·관통, 지형·하천·요새·참호, 제공권·근접 항공 지원).
- **배경음악**: 상황에 따라 곡이 바뀝니다. 평화(왈츠·새벽의 들판), 긴장(폭풍 전야), 전쟁(강철의 폭풍·불타는 전선), 우세할 때(진군), 밀릴 때(최후의 방어선), 승전(개선), 패전(레퀴엠). 선전포고·적국 항복·동맹국 함락 때는 짧은 효과 음악이 겹쳐 울립니다. 현악·금관·목관·피아노·합창·팀파니·작은북을 배음·필터·엔벨로프로 흉내 내고 홀 잔향을 입혔습니다. 사파리 정책상 화면을 처음 탭한 뒤부터 소리가 나며, 메뉴에서 켜고 끄기·음량·음악 감상을 고를 수 있습니다.
- **AI**: 전선 길이와 위협에 따른 배치, 기갑 집중 돌파, 해안 수비대, 원정군·상륙 작전, 장비 수요에 맞춘 생산, 역사적 일정에 맞춘 선전포고. AI끼리 두면 대체로 1940년 프랑스 항복, 1941년 바르바로사, 1943년 이탈리아 휴전, 1944~45년 독일 항복으로 흘러가지만 판마다 전개는 달라집니다.

## 개발 도구

```sh
node tools/validate-content.mjs          # 이벤트·중점·효과 참조 검사
node tools/simulate.mjs 3600             # 브라우저 없이 AI끼리 진행(일 수)
node tools/preview/play.mjs <시나리오.mjs> # Playwright로 아이폰 화면 캡처
cd tools && NE_DIR=<Natural Earth 경로> node build-map.mjs   # data/map.json 재생성
```

지도는 Natural Earth 1:10m 행정 구역 데이터를 1936년 국경에 맞게 다시 묶어 만들었습니다.
